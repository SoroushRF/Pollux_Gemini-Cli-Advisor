# Pollux v1.2 Calibration Notes

Pollux v1.2 is a repaired candidate set, not a final benchmark freeze.

## What Changed

- Live model workspaces must run outside the repository tree.
- Synthetic task workspaces include task-local `package.json` files so
  `npm test` cannot climb to the Pollux repository root.
- Hidden tests remain verifier-only and are injected into cloned verifier
  workspaces after the agent run.
- Early-stop oracle passes are recorded separately so solved runs are not
  mislabeled as generic missing telemetry when response telemetry flushes late.
- Invalidations are bucketed as capability, infrastructure, or runtime
  invalidations in all-sample diagnostics.
- Five brutal hard candidates replace weak or under-specified hard slots.

## Candidate Set

Use `selected-task-set.v1.2.json` for A/E calibration. It intentionally has
status `pending_calibration`; do not use it for final FD claims until the A/E
review passes and the file is frozen.

## Calibration Command Shape

Run A/E only before FD:

```powershell
npm.cmd run benchmark:pollux:real:pilot -- --campaign-id pollux-v1_2-calibration-AE-001 --condition-ids A,E --repeats 3 --entrypoint bundle --pricing-snapshot docs/core/pollux/P4-13_REAL_BENCHMARK_PRICING_SNAPSHOT_2026-04-24.json --task-ids pollux-v1-cross-contract-easy-01,pollux-v1-test-intent-easy-01,pollux-v1-guarded-migration-easy-01,pollux-v1-source-truth-easy-01,pollux-v1-multi-artifact-easy-01,pollux-v1-cross-contract-medium-01,pollux-v1-test-intent-medium-01,pollux-v1-guarded-migration-medium-01,pollux-v1-source-truth-medium-01,pollux-v1-multi-artifact-medium-01,pollux-v1-cross-contract-brutal-01,pollux-v1-test-intent-brutal-01,pollux-v1-guarded-migration-brutal-01,pollux-v1-source-truth-brutal-01,pollux-v1-multi-artifact-brutal-01 --allow-overwrite true --max-wall-clock-ms 180000 --max-model-responses 15 --keep-scratch-directories true
```

## Acceptance Gates

- Easy/control: A should pass most runs; E failures require infra or ambiguity
  review.
- Medium: A may pass or fail; E should usually pass.
- Hard: A pass rate must be no more than 50%, or A must show repeated
  response-ceiling pressure; E pass rate must be at least 67%.
- Infra invalidation rate must be no more than 20%.
- FD results must not be used to relabel, reject, or harden tasks before freeze.
