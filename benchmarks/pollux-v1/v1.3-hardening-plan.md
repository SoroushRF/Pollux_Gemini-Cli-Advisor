# Pollux v1.3 Medium/Hard Hardening Plan

Pollux v1.2 fixed benchmark infrastructure validity, but A-track calibration
showed the current medium/hard suite is too easy or too shallow. There were no
infra invalidations in the latest A-track medium/hard runs, so the high A
success rate is real task-design signal. v1.3 replaces or revises medium/hard
tasks before any final FD run.

## Decisions

- Keep the five easy controls unchanged.
- Replace all medium and hard task IDs with v1.3 IDs.
- Keep the source-truth brutal and guarded-migration brutal concepts, but revise
  them under new IDs.
- Do not run FD until A/E calibration confirms the v1.3 labels.
- Use SWE-bench task archetypes only; do not copy GitHub code or exact tasks.

## Calibration Gates

- Medium tasks may pass under A, but should require meaningful work and hidden
  alternate fixtures.
- Hard tasks should have A pass rate <= 50% or show clear ceiling pressure, with
  E pass rate >= 67% after infra-clean calibration.
- Any E failure must be inspected for ambiguity or overly broad/narrow hidden
  tests before freeze.
